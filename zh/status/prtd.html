永久居民旅行证件（PRTD）

没有有效 PR 卡时返回加拿大

永久居民旅行证件（Permanent Resident Travel Document，简称 PRTD） 是提供给加拿大永久居民的一种旅行文件， 适用于人在加拿大境外且没有有效 PR 卡的情况。

当永久居民需要搭乘飞机、商业巴士、火车或船只等 商业交通工具返回加拿大时， 通常会使用 PRTD。

PRTD 并不会赋予永久居民身份。 申请人必须已经是加拿大永久居民。

PRTD 也不能代替 PR 卡续期。 永久居民返回加拿大后， 如果没有有效 PR 卡，通常应申请新的 PR 卡。

重要区别

PRTD 并不会赋予您永久居民身份

PRTD 只适用于已经拥有加拿大永久居民身份的人。

它只是一份旅行文件， 帮助没有有效 PR 卡、符合条件的永久居民返回加拿大。

因此，它与通过快速通道（Express Entry）、家庭担保、 省提名或其他移民项目申请永久居民身份完全不同。

PRTD = 旅行证件

您必须已经是永久居民， 才可能符合 PRTD 资格。

常见情况

哪些情况下可能需要 PRTD？

永久居民有时会在境外遇到 没有有效 PR 卡文件的情况。

01

PR 卡在境外过期

您离开加拿大后， 在准备返加前 PR 卡已经过期。

02

PR 卡遗失或被盗

您在加拿大境外期间遗失了有效 PR 卡， 或 PR 卡被盗。

03

PR 卡损坏

PR 卡损坏， 无法再用于搭乘商业交通工具旅行。

04

出行前新 PR 卡尚未签发

您已经在加拿大申请新的 PR 卡， 但在卡片签发或收到前就离开了加拿大。

商业交通出行

为什么永久居民登乘商业交通工具时可能需要 PRTD？

永久居民搭乘商业交通工具前往加拿大时， 通常需要出示可接受的文件， 证明其有权以永久居民身份进入加拿大。

有效 PR 卡通常可以满足这一要求。

如果没有有效 PR 卡， PRTD 可以作为搭乘飞机、巴士、船只或火车 返回加拿大所需的旅行文件。

航空公司通常不会接受已过期 PR 卡

过期 PR 卡通常不能作为 搭乘商业航班返回加拿大所需的有效登机文件。

评估我的旅行文件

私人车辆

乘私人车辆返回加拿大的规则不同

商业交通工具的文件要求， 与乘私人车辆从陆路边境进入加拿大的要求不同。

私人车辆可以包括自己拥有、借用或租用的汽车、 卡车、摩托车或休闲车辆。

永久居民乘私人车辆从陆路返回加拿大时， 不适用商业交通工具的 PR 卡或 PRTD 登乘要求。 在加拿大边境接受检查时， 可以使用其他文件证明身份和永久居民身份。

商业交通与私人车辆出行的规则不同

是否需要 PRTD， 可能取决于您准备采用什么方式返回加拿大。

评估我的返加选择

居住义务

IRCC 会审核您是否满足永久居民居住义务

PRTD 申请并不只是单纯的旅行申请。 IRCC 可能会审核永久居民是否满足加拿大的居住义务。

01

730 个符合要求的天数

永久居民通常需要在适用的 5 年期间内 至少有 730 个符合要求的天数。

02

这些天数不需要连续

符合要求的天数可以在不同时间累积， 不需要连续。

03

部分境外时间也可能计算

如果满足特定法律要求， 某些境外时间也可能计入居住义务。

04

旅行记录很重要

申请人必须准确提供 相关期间内离开加拿大的记录。

成为永久居民未满 5 年的人

您成为永久居民还不到 5 年吗？

居住义务的评估方式， 会根据持有永久居民身份的时间长短而不同。

如果您成为永久居民还不到 5 年， IRCC 通常会考虑您是否仍有可能 在成为永久居民满 5 周年前 累积至少 730 个符合要求的天数。

这与简单计算 PRTD 申请前一段期间内 是否已有 730 天并不相同。

正确的 5 年评估期间非常重要

提交申请前， 应认真完成居住义务计算。

计算我的居住天数

可计算的境外时间

境外时间可以计入 730 天吗？

在特定情况下， 在加拿大境外的时间可以计入永久居民居住义务。

01

陪同加拿大公民

在境外陪同加拿大公民配偶、同居伴侣， 或在某些情况下陪同加拿大公民父母时， 部分时间可能可以计算。

02

在加拿大境外工作

为符合条件的加拿大企业 或加拿大公共行政机构在境外从事某些全职工作， 相关时间可能可以计算。

03

陪同在境外工作的永久居民

如果陪同永久居民配偶、伴侣或父母在境外， 且该永久居民因符合条件的加拿大境外就业而满足相关要求， 某些时间也可能可以计算。

居住义务问题

如果不满足 730 天要求怎么办？

如果申请人不满足永久居民居住义务， PRTD 申请可能产生重要法律后果。

在认定不满足要求前， 应仔细审核正确的居住评估期间、实际在加时间 以及任何可计算的境外时间。

如果仍然存在居住天数不足， 根据个人情况，人道与同情因素可能具有相关性。

不利的居住义务裁定 可能影响申请人的永久居民身份。

不要把这种情况当作普通旅行文件申请

如果您长期在加拿大境外居住， 提交 PRTD 前应先评估居住义务。

评估我的居住情况

人道与同情因素

特殊情况可能具有相关性

如果永久居民不满足居住义务， IRCC 在决定是否仍应保留永久居民身份时， 可能考虑人道与同情因素。

相关因素取决于个人案件， 可能涉及家庭、医疗、与儿童有关的因素 或其他具有说服力的情况。

这类申请应清楚解释 为什么无法满足居住义务， 并提供支持所依赖情况的证明材料。

H&C 取决于具体案件

人道因素并不是居住义务的自动豁免。 必须结合完整情况和支持证据进行评估。

评估我的 H&C 因素

PRTD 有效性

PRTD 可以签发为单次或多次入境

PRTD 通常签发为单次入境， 让永久居民返回加拿大。

在适当情况下，IRCC 可能签发多次入境 PRTD。 申请人通常应满足居住义务， 并说明为什么需要多次旅行。

可能可以申请多次入境

申请多次入境 PRTD 时， 可以说明具体情况并请求 IRCC 考虑， 但是否批准属于酌情决定。

PRTD 并不是为了长期取代 PR 卡。

PR 卡签发给加拿大境内的永久居民， 不会邮寄到加拿大境外。

常见误解

关于 PRTD 需要了解的重要事项

PRTD 经常被误认为是 PR 卡 或永久居民申请。

!

PRTD 会给我永久居民身份

不是。您必须已经拥有永久居民身份 才可能符合资格。

!

PRTD 就是 PR 卡

不是。PRTD 是旅行证件， 主要用于在没有有效 PR 卡时返回加拿大。

!

PR 卡过期，所以我失去 PR 身份了

PR 卡过期本身 不会终止永久居民身份。

!

我可以在加拿大境内申请

不是。PRTD 面向人在加拿大境外的永久居民。

!

所有 PRTD 都是多次入境

不是。PRTD 通常签发为单次入境， 但某些情况下可以考虑多次入境。

!

居住义务不重要

IRCC 在审理 PRTD 申请时， 可以审核是否满足永久居民居住义务。

重要信息

PRTD 申请可能触发永久居民居住义务审核

虽然 PRTD 的主要作用是提供旅行文件， 但 IRCC 可能需要通过该申请判断 申请人是否继续满足永久居民居住义务。

因此，长期离开加拿大的永久居民 在提交申请前应先了解自己的居住义务情况。

如果是否满足居住义务存在不确定性， 应将不利裁定可能产生的法律后果 纳入整体策略考虑。
