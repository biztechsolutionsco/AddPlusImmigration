永久居民卡

PR 卡是您现有永久居民身份的证明

永久居民卡（Permanent Resident Card，简称 PR Card） 是证明您拥有加拿大永久居民身份的正式文件。

续期 PR 卡并不等于重新申请永久居民身份。 您已经拥有永久居民身份， 这项申请只是申请一张新的永久居民身份证明文件。

PR 卡在国际旅行时尤其重要。 永久居民搭乘飞机、火车、巴士或船只等商业交通工具返回加拿大时， 通常需要有效 PR 卡以及有效护照或旅行证件。

PR 卡申请还可能涉及审核 您是否继续满足加拿大永久居民居住义务。

PR 卡与永久居民身份

PR 卡过期并不代表永久居民身份过期

永久居民卡与永久居民身份是两个不同的概念。

PR 卡是一张用于证明永久居民身份的实体文件。 卡片上的到期日只是文件本身的到期日， 并不会自动终止永久居民身份。

如果您在加拿大居住期间 PR 卡过期， 并不会自动变成临时居民， 也不会自动失去留在加拿大的权利。

永久居民身份只能通过特定法律程序失去， 例如正式身份裁定、自愿放弃身份、 可执行的遣返令，或成为加拿大公民。

PR 卡过期 ≠ 永久居民身份过期

续期 PR 卡只是更换身份证明文件， 并不代表重新申请成为永久居民。

居住义务问题

如果看起来没有 730 个符合要求的天数怎么办？

如果居住天数不足， 在把案件当作普通 PR 卡续期提交前应谨慎评估。

并不是所有境外天数都一定不能计算， 而且首先需要确定正确的 5 年评估期间。

如果不满足居住义务， 根据案件事实，人道与同情因素 也可能与 IRCC 的评估有关。

PR 卡过期本身不会终止永久居民身份。 即使某人可能不满足居住义务， 在正式作出身份裁定前仍然是永久居民。

不要把这种情况当作普通续期

评估我的返加选择

永久居民旅行证件（PRTD）

什么是 PRTD？

永久居民旅行证件（Permanent Resident Travel Document，简称 PRTD） 是供某些人在加拿大境外且没有有效 PR 卡时使用的临时旅行文件。

它可以让符合条件的永久居民 搭乘商业交通工具返回加拿大。

PRTD 可以签发为单次入境， 在适当情况下也可能签发多次入境。 返回加拿大后，如果没有有效 PR 卡， 通常应申请新的 PR 卡。

PR 卡和 PRTD 是不同的文件

PR 卡通常在加拿大境内申请或领取。 PRTD 通常用于人在加拿大境外、没有有效 PR 卡 但需要返回加拿大的情况。

加急处理

急需 PR 卡？

IRCC 在某些符合条件的情况下 提供 PR 卡加急处理。

申请加急处理时， 必须提供能够支持紧急原因和旅行计划的证据。

即使符合加急条件， IRCC 也不保证新 PR 卡会在计划旅行日期前签发。

IRCC 当前指引会区分距离旅行超过 3 周 与未来 3 周内旅行的情况。 IRCC 不保证加急处理，并说明无法在少于 3 周内处理 PR 卡申请。 如果没有有效 PR 卡就离开加拿大， 之后可能需要在境外申请 PRTD 才能搭乘商业交通工具返回。

近期有旅行计划？

如果有紧急旅行计划， 而 PR 卡已经过期或即将到期， 在安排行程前应同时评估加急处理和 PRTD 的影响。

重要信息

PR 卡申请可能触发居住义务审核

虽然 PR 卡续期并不是新的永久居民申请， IRCC 仍可能审核申请人是否继续满足 永久居民居住义务。
