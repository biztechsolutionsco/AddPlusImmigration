加拿大经验类（CEC）

什么是加拿大经验类（CEC）？

加拿大经验类（CEC）是加拿大通过快速通道（Express Entry）系统管理的联邦经济类移民项目之一。

该项目面向已在加拿大取得符合要求的技术类工作经验， 并希望成为加拿大永久居民的申请人。

对于符合条件的临时外国工作者，以及后来取得符合要求的 加拿大工作经验的原国际学生而言，CEC 可能是一条重要的移民路径。

满足 CEC 的最低要求可以使符合条件的申请人进入快速通道候选池， 但并不保证一定会收到永久居民申请邀请（ITA）。

基本信息

工作经验 过去 3 年内至少 1 年（1,560 小时）符合要求的加拿大工作经验
符合要求的职业 NOC TEER 0、1、2 或 3
语言要求 TEER 0–1：CLB/NCLC 7；TEER 2–3：CLB/NCLC 5
工作邀请 不要求
学历 无最低学历要求

申请资格

CEC 主要申请要求

申请人必须满足项目的最低要求， 才能符合 CEC 的申请资格。

01

加拿大工作经验

通常需要在申请前 3 年内取得至少 1 年、即 1,560 小时的 符合要求的加拿大工作经验。

02

技术类职业

您用于申请的加拿大工作经验 必须属于 NOC TEER 0、1、2 或 3 的职业。

03

合法授权工作

符合要求的工作经验必须是在您持有临时居民身份， 并获准在加拿大工作的情况下取得的。

04

语言能力

您必须达到与符合要求职业的 TEER 等级相对应的 最低英语或法语水平。

05

计划在魁北克省以外定居

CEC 申请人必须计划在魁北克省以外定居。 即使符合要求的加拿大工作经验是在魁北克取得， 只要申请人能够证明计划在加拿大其他地区定居，仍可能符合要求。

06

快速通道资格

满足 CEC 要求后，申请人还需要创建快速通道档案， 并在快速通道筛选系统中参与排名。

工作经验

哪些工作经验可以计入？

并非所有在加拿大的工作经历 都一定可以用于满足 CEC 的工作经验要求。

✓

有薪的 TEER 0、1、2 或 3 工作

符合要求的加拿大工作经验通常必须是有薪工作， 且职业属于 NOC TEER 0、1、2 或 3。

✓

全职或等量兼职

所需工作经验通常可以通过全职工作， 或等量的符合要求的兼职工作累积。

✓

可来自多个符合要求的工作或 NOC

符合要求的加拿大工作经验通常可以来自多个符合条件的工作或 NOC， 只要合并后的工作经验满足适用的 CEC 要求。

✓

近期加拿大工作经验

符合要求的工作经验必须位于 CEC 申请前规定的 3 年期限内。

重要区别

通常不能计入的工作经验

正确判断哪些工作经验符合要求， 是 CEC 资格评估中的重要部分。

01

全日制学习期间的工作

在全日制学习期间取得的加拿大工作经验 不计入 CEC 的最低工作经验要求。

02

未经授权的工作

在没有所需工作授权的情况下取得的工作经验， 不属于符合要求的加拿大工作经验。

03

不符合要求的职业

不属于 NOC TEER 0、1、2 或 3 的工作经验， 不能满足 CEC 的最低技术类工作经验要求。

04

自雇工作

自雇工作通常不计入 CEC 所要求的最低加拿大工作经验。 某些提供公共资金医疗服务的医生， 可能根据特别公共政策符合要求。

语言要求

最低语言要求取决于您的职业 TEER 等级

CEC 申请人必须通过认可的语言考试， 证明自己的英语或法语听、说、读、写能力。

如果符合要求的工作经验属于 TEER 0 或 TEER 1 职业， 每项语言能力通常至少需要达到 英语 CLB 7 或法语 NCLC 7。

如果符合要求的工作经验属于 TEER 2 或 TEER 3 职业， 每项语言能力通常至少需要达到 英语 CLB 5 或法语 NCLC 5。

认可的语言考试

IRCC 接受指定的英语和法语语言考试用于快速通道。 考试成绩必须满足适用的 CEC 语言要求， 并在 IRCC 要求的相关时间点保持有效。

其他因素

学历与工作邀请

满足 CEC 最低申请资格并不要求学历或工作邀请， 但这些及其他因素仍可能影响您的快速通道排名。

✓

无最低学历要求

CEC 本身没有最低学历要求。 但符合条件的学历可能为您的 CRS 分数加分。

✓

不要求工作邀请

符合 CEC 资格不需要工作邀请。

✓

CRS 分数仍然重要

进入快速通道候选池后， 您的档案会按照综合排名系统（CRS）进行排名。

✓

还可能有其他移民路径

根据您的具体情况，您也可能符合省提名 或其他永久居民申请路径的资格。

申请流程

CEC 申请流程

CEC 申请通过快速通道系统进行管理。

1

审核您的工作经验

确认您的加拿大工作经历符合 CEC 要求。

2

完成语言考试

取得有效语言成绩，并达到您职业对应的最低语言要求。

3

创建快速通道档案

如符合要求，提交快速通道档案并进入候选池。

4

等待申请邀请

申请人在快速通道候选池中按分数排名， 并可能在适用的邀请轮次中收到申请邀请（ITA）。

5

提交永久居民申请

获得邀请后，提交完整的永久居民申请 以及所需支持材料。

重要信息

加拿大工作经验需要仔细评估

曾经在加拿大工作，并不代表相关经验 自动符合 CEC 的要求。

您的职业、NOC 分类、工作职责、工作日期、工作时数、 是否具备工作授权，以及工作期间是否在读， 都可能影响 CEC 资格判断。

您的工作证明材料也应准确支持您在快速通道档案 和永久居民申请中申报的工作经验。
